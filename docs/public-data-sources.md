# Публичные видео: применимость к текущему ML-эксперименту

Источники и доступ проверены **18.10.2026**. Эти наборы описывают действия людей и взаимодействие с предметами. Они не содержат эталона банковских нарушений R20-A/B/C или R22. Переносить их метки в нормативные классы нельзя. В пределах текущих двух часов приоритет — проверка банковского анализатора на неизменной локальной разметке; публичные данные могут дать только дополнительную диагностику базового распознавания действий.

## Проверенные источники

| Набор | Что проверено | Применимость и ограничения |
| --- | --- | --- |
| [PIP-175k, Visym](https://visym.github.io/collector/pip_175k/) | 184 379 клипов, 66 классов; полный архив 54,02 GB; лицензия CC BY 4.0 | Есть действия с предметами и передача человеку. Сцены обрезаны вокруг основного участника; авторы указывают, что класс покупки у кассира временно удалён. Не даёт подтверждения принадлежности денег или завершённости банковской операции. |
| [RetailAction, Standard AI](https://huggingface.co/datasets/standard-cognition/RetailAction) | 21 000 пар ракурсов; классы `take`, `put`, `touch`; `take` составляет 97,2% действий. [Архивы](https://huggingface.co/datasets/standard-cognition/RetailAction/tree/main/data): train 26,08 GB, validation 1,94 GB, test 3,84 GB | Подходит для отдельной проверки различения взять/положить/коснуться и согласованности ракурсов. До 32 кадров выбраны по движению; исходное время берётся из метаданных, а не из предположения о равномерной выборке. |
| [MERL Shopping Dataset](https://www.merl.com/research/downloads/MERL_Shopping_Dataset) | 106 записей примерно по две минуты, одна верхняя камера, пять действий около полки; официальный ZIP видео — 1 848 186 603 байта | Подходит для проверки коротких действий рук и временного поиска. Не проверяет разнообразие ракурсов банка, роли кассир/клиент, деньги или нормативные условия. |

У PIP демонстрационная HTML-выборка занимает около 87 MiB, а не несколько килобайт. Полный архив не подходит для этого короткого запуска. Не путайте MIT-лицензию программного репозитория Visym с CC BY 4.0 самого датасета. [Описание PIP и лицензия](https://visym.github.io/collector/pip_175k/)

RetailAction использует [собственную лицензию Standard.AI](https://huggingface.co/datasets/standard-cognition/RetailAction/blob/main/LICENSE): предусмотрены указание автора, сохранение условий/уведомления, запрет реидентификации; при доходе от использующих данные продуктов/услуг свыше $10 000 требуется отдельная лицензия. Это не набор с автоматически применимой MIT/Apache-лицензией. Публичное скачивание метаданных проверено без токена; инструкция карточки о токене с правом записи для этой проверки не нужна.

[Официальный ReadMe MERL](https://www.merl.com/pub/tmarks/MERL_Shopping_Dataset/ReadMe.md) разрешает бесплатное использование данных и документации для исследования и образования. Это не подтверждение разрешения на произвольное коммерческое распространение. Там же заданы отдельные группы участников для train/validation/test и формат временных меток. Метки доступны отдельным ZIP примерно 64 KiB в [каталоге MERL](https://www.merl.com/pub/tmarks/MERL_Shopping_Dataset/).

## Что уже сделано локально

В `.local_ml/public-data-audit-v16/` сохранены небольшие официальные описания, лицензия RetailAction, список файлов, архив меток MERL и метаданные архивов. Манифест `audit.json` содержит URL, размеры и SHA-256 первых семи файлов. Дополнительные проверки Range сохранены отдельно. Видео, обучающие веса и зависимости этим аудитом не скачивались; банковские материалы не читались и не передавались в сеть.

На обоих видеохранилищах проверен ответ **HTTP 206** на запрос диапазона байтов. Это позволяет позднее получить отдельные записи без загрузки архива целиком. Однако Range сам по себе не выбирает сбалансированную выборку:

- У MERL прочитан центральный каталог ZIP: 106 настоящих MP4. Четыре заранее выбранных validation-источника — участники 21–24, первая сессия — суммарно занимают **68 465 281 байт** в архиве, около 65,3 MiB. Они ещё не скачаны. Локальный `merl-video-index.json` содержит размеры и смещения.
- RetailAction распространяется в TAR с PAX/AppleDouble и длинным начальным списком каталогов. Первые 24 прочитанных заголовка не дали ни видео, ни `metadata.json`. Для корректной подвыборки нужен индекс реальных записей; нельзя считать произвольный префикс TAR готовым набором.

В начале аудита свободное место C: составляло **2,88 ГиБ**. После очистки приложений владельцем повторный замер 18.10.2026 показал **49,45 ГиБ**. Это место на диске: доступный ОС объём RAM остаётся 15,25 ГиБ. Перед дальнейшими загрузками проверьте актуальный остаток. Полные архивы не загружались, существующие веса и результаты агент не удалял.

## Повторить проверку метаданных без SDK и установки пакетов

Из корня проекта можно запустить:

```powershell
.\.venv\Scripts\python -m ml_tools.public_archive_metadata merl --output .local_ml/public-data-audit-v16/merl-index-repeat.json
.\.venv\Scripts\python -m ml_tools.public_archive_metadata retail --output .local_ml/public-data-audit-v16/retail-header-repeat.json
```

Выбирайте новое имя результата. Утилита использует только стандартную библиотеку, не извлекает архив и не принимает произвольный URL. Для MERL читаются точная конечная запись ZIP и центральный каталог; для RetailAction — один 512-байтовый TAR-заголовок. Ответ без правильных HTTP 206 и `Content-Range` отклоняется до чтения тела. Максимум одного диапазона — 2 MiB. Если архив изменил неподдерживаемый формат, работа прекращается без перехода к полной загрузке. `--retail-offset` предназначен только для смещения проверенного следующего заголовка, которое возвращает предыдущий результат; содержимое файлов этой командой не скачивается.

## Ограниченный следующий эксперимент

После решения вопроса диска можно выделить **не более 20 минут и 100 MiB** на отдельную диагностику MERL с уже установленной Qwen. Сначала получить четыре указанных MP4 адресными диапазонами, проверить размер, ZIP CRC и декодирование; не применять `extractall` и пути из архива как пути записи. Эта загрузка и диагностический прогон пока не выполнены.

Для каждого источника заранее зафиксировать окна 0–24, 36–60 и 72–96 секунд, сверить доступность интервалов и соответствующие авторские метки. Запрашивать только пять общих действий MERL и недостаток видимости в отдельной схеме ответа, без R20/R22. Сохранить ошибки классов/времени, число доступных примеров каждого класса, отказы и время обработки. Отсутствующие в выборке классы не считать проверенными.

Это проверка базового понимания движения, а не обучение весов, калибровка уверенности банковского события или доказательство качества на новом банковском ракурсе. Если публичные примеры используются в prompt как демонстрации, они становятся материалом настройки и не входят в проверочную выборку. Любое изменение банковского prompt после этого требует отдельного полного сравнения на прежних локальных видео: исправление одной сцены не должно скрывать новые ложные тревоги и пропуски.
