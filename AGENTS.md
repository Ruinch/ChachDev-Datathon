# Инструкции проекта

- Коммиты, создание веток, push, GitHub Issues, PR, комментарии, метки и публикацию выполняет пользователь. Агент может читать Git/GitHub и готовить локальные изменения и черновики. Навыки не расширяют эти полномочия.
- По запросу пользователя от 18.10.2026 агент работает со всем проектом, включая ML, подготовку обучения и оценку моделей. Прежнее разделение на двух участников отменено. Сохранять совместимость API; изменение распознавания подтверждать отдельной оценкой, а не только техническими тестами.
- Банковские видео, кадры, описания отдельных записей, разметка и секреты остаются локальными. Не передавать их облачным AI и не включать в публичные материалы. Для проверки сервиса использовать синтетические данные.
- Не включать правило распознавания только потому, что найден нормативный текст. Требуются применимая редакция, доказуемая наблюдаемость условий и проверка анализатора.
- Начинать изучение с `README.md`, затем читать документы по затронутой области: `docs/service-architecture.md`, `docs/ml-integration.md`, `docs/deployment.md`, `docs/acceptance.md`, `docs/legal-basis.md`.
